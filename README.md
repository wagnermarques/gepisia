# GEPISIA

**GEPISIA** é um projeto resultado da apresentação sobre Inteligência Artificial (IA) no grupo de pesquisa **GEPIS** (Grupo de Estudos e Pesquisas em Inovação e Sustentabilidade).

## Sobre o Projeto

Este projeto demonstra conceitos e aplicações práticas de Inteligência Artificial abordados na apresentação do grupo GEPIS. O objetivo é explorar técnicas de IA de forma didática, mostrando exemplos práticos que podem ser estudados e adaptados.

## Tópicos Abordados

- Introdução à Inteligência Artificial
- Machine Learning (Aprendizado de Máquina)
- Exemplos práticos com Python

## Estrutura do Projeto

```
gepisia/
├── README.md           # Documentação do projeto
├── requirements.txt    # Dependências Python
└── gepisia.py          # Script principal com exemplos de IA
```

## Pré-requisitos

- Python 3.8+
- pip

## Instalação

```bash
pip install -r requirements.txt
```

## Uso

```bash
python gepisia.py
```
